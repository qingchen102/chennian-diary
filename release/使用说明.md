# 尘年往事 · 手札日记

一款完全离线、双开本的拟物电子日记。纸黄灯暖，皮革木桌，翻页有风。

> 双击 **`尘年往事.exe`** 即可开始书写。无需安装、无需联网。

> 说明：因第三方字体授权，包内不含「手写体」字体文件，书写界面会自动回退到系统楷体；如你已获得该字体授权，可将 TTF 文件放入 `app\assets\fonts\` 目录。

---

## 一、怎么开始

1. 把整个文件夹放到你喜欢的位置（U 盘、桌面、网盘都行，保持 `尘年往事.exe` 与 `app` 文件夹在一起）。
2. 双击 `尘年往事.exe`，应用窗口会自动打开。
3. 第一次打开会看到书架上的两本书：**日记本**（暖纸棕皮）与**随笔本**（旧纸墨绿布面）。
4. 点一本书 → 翻到最后一页的「+」→ 开始写。

> 关闭窗口即自动退出，数据不会丢（页面刷新/重载也不会影响程序）。

| 元信息 | 天气（下拉 + 自由输入）、地点、标题（必填）；**页眉一行**排布“日期 · 天气 · 地点 · 标题”，放不下时标题自动换到下一行，标题略大一点，文字正好压在横线上 |

## 三、常用操作

- **翻页**：点页面左缘 → 往前（更早）；点右缘 → 往后（更新）；也可左右滑动 / 键盘 ← →。
- **写新篇**：翻到最后一页，点中央的「+」。
- **改旧篇**：阅读页右上角浮现的铅笔按钮。
- **看目录**：阅读页右上角「☰ 目录」，点任意标题直达那一篇。
- **加批注**：阅读时用鼠标拖选几个字（触屏长按选择），点浮出的「✎ 批注」写下想法；正文只多一条**下划线标记和一个小角标**，不遮字、排版不变。**点角标（或下划线）弹出批注卡片**，点别处即关闭，平时干干净净。
- **编辑器翻页**：写满一页会自动续到下一页；**左页是当前书写页**，**右页显示下一页/下一篇**；点书页左右边缘（或 ← → 键）可前后翻页检查，**翻页后光标回到第一行**，直接继续写即可；在第一行输入不会误触发翻页。写了几页，保存后阅读就是几页。
- **调字号**：设置 → 字号，可看“每行约 X 字”的实时提示，调到 20–30 字最像手写本子。
- **盖心情章 / DIY 印章**：写日记时在底部「心情：」一栏点一个表情即可；想用自己的图做印章，点旁边的 **「🖼」** 选一张图片（PNG 带透明底效果最好），它会出现在表情旁边，点它盖章、再点取消；把鼠标悬在自选印章上会出现小 ✕，点它删除这枚印章。阅读时印章斜盖在页角。
- **看图片**：点击正文插图或文末小图放大查看。
- **检索 / 统计 / 设置**：书架右上角三个铜钮。
- **导出备份**：设置 → 导出备份为 ZIP，含全部日记、批注与图片。

## 四、自己调整外观（纸张宽度 / 字号 / 行距）

> 应用完全由普通文本文件组成，用记事本即可修改。改完**关掉应用重开**生效。

**1. 纸张宽度与高度**
打开 `release\app\css\style.css`，找到：

```css
#view-book .sheet {
  width: min(94vw, 980px); height: min(88vh, 640px);
}
```

- `980px` = 摊开整本书的最大宽度（两个页面）；`94vw` = 宽度占窗口的比例，两者取较小者。
- `640px` = 书的最大高度；`88vh` = 高度占窗口的比例。
- 想宽一点就改大 `980px`（例如 `1100px`）；想矮一点就改小 `640px`。
- 书页左右留白在 `.page { padding: 46px 9% 58px }` 这一行，`9%` 是左右边距。

**2. 默认字号（写字的默认大小）**
打开 `release\app\js\store.js`，找到：

```js
fontSize: 16,
```

改成你喜欢的数字（如 17、18）即可。注意：行距与横线间距都跟着字号自动缩放（每行恰好一行、字落在线上），所以只改字号即可，不用管横线。

**3. 字号下拉的可选项**
打开 `release\app\js\views\settings.js`，找到 `[15, 16, 17, 18, 19, 20, 22]`，增删数字即可让设置里的下拉多几个选项。

**4. 行距 / 横线**
默认行距是字号的 2 倍（`line-height: 2`），横线间距也自动等于一行。一般不需要改；若确实要改，在 `release\app\css\style.css` 里搜 `line-height: 2`（正文与书写区两处）一起改，并同步改横线渐变里的 `* 2` 为同样的倍数。

**5. 翻页热区（左右边缘点击翻页的敏感区）**
默认是窗口最左/最右的 **30px 窄条**（为了不挡住页面边缘的文字选择）。想再大一点或小一点，打开 `release\app\css\style.css`，搜索 `.flip-zone`，把 `width: min(30px, 3%)` 里的 `30px` 改大（如 `60px`）或改小即可。

## 五、导入字体（离线可用）

字体分两种：

- **系统已装字体**：不用任何文件。在 `release\app\js\store.js` 的 `FONTS` 列表里加一行 `{ name: "微软雅黑", css: '"微软雅黑", "Microsoft YaHei", sans-serif' }`（格式照抄现有条目），设置里的字体下拉就会出现它。
- **字体文件（.ttf / .otf / .woff2）**：想用电脑上没有的字体（换电脑也能显示），按下面三步：
  1. 把字体文件复制到 `release\app\assets\fonts\`（没有就新建 `fonts` 文件夹）。
  2. 在 `release\app\css\style.css` **最顶部**加一行声明：
     ```css
     @font-face { font-family: "我的字体"; src: url("../assets/fonts/文件名.ttf"); }
     ```
     （`我的字体` 和文件名换成你自己的。）
  3. 在 `release\app\js\store.js` 的 `FONTS` 里加：`{ name: "我的字体", css: '"我的字体", "楷体", serif' }`。
   4. 关掉应用重开，设置 → 字体 里就能选了。

> **加了字体却不生效？** 多半是这三种情况：
> 1. **路径写错**：`src` 里必须是相对路径 `url("../assets/fonts/文件名.ttf")`，**不要**写成 `file:///D:/...` 这种绝对路径——应用是网页方式运行的，浏览器禁止网页加载 `file://` 文件，字体永远加载不出来（而且绝对路径换个位置就失效了）。
> 2. **名字不一致**：`@font-face` 里的 `font-family: "名字"` 必须和 `store.js` 里 `css: '"名字", ...'` 引用的是**同一个名字**（照抄第 2 步和第 3 步的 `我的字体` 即可），一个写"手写体"、另一个写文件名英文名，浏览器找不到就会静默回退。
> 3. **字体文件本身损坏**：有些网上下的字体在 Word/PS 里能显示，但文件内部数据是坏的，浏览器会拒绝加载。判断方法：打开应用后按 `F12` → Console（控制台），看有没有 `Failed to decode downloaded font` 之类的红字；有就说明字体文件坏了，需要重新下载或换一个来源。可以用 `C:\Windows\Fonts` 里的系统字体（如 `simkai.ttf` 楷体）替换试一下，能显示就证明操作步骤没问题，是字体文件的问题。

## 六、数据在哪

- 数据保存在 `release\data\` 目录（IndexedDB），**只在本机**，完全离线。
- 备份导出为 ZIP 后可随身保存；换电脑时把 `release` 整个文件夹拷走即可。
- 想清空重来：删除 `release\data\` 文件夹。

## 七、小知识 / 常见问题

- **端口占用**：应用使用本地端口 38613 提供页面。若端口被占，会直接复用已在运行的应用实例（不会开第二个）。
- **需要联网吗**：不需要。所有内容（含诗词库、字体）都是本地的。
- **字体**：使用系统中文字体（楷体、行楷、隶书、幼圆等 12 种），换电脑后字体略有差异属正常。
- **删掉重装**：直接删除整个 `release` 文件夹即可，无残留、无注册表。
- **以后想升级**：把新版 `app` 文件夹覆盖到 `release\app` 即可，日记数据保留。

## 八、技术备忘（写给好奇的人）

- `尘年往事.exe`：C#（.NET 10，单文件自包含）启动器——内置静态文件服务器 + 唤起 Edge 应用模式窗口。
- `app\`：原生 HTML/CSS/JS（ES 模块），零构建、零依赖。
- 存储：浏览器 IndexedDB（`chennian-diary`）；导出：手写 ZIP（Deflate + CRC32）。
- 翻页：CSS 3D 书页绕书脊翻转；分页：按页宽/页高把 HTML 流式切页（超长段落按行拆分）；批注：段落 id + 字符偏移定位，正文只加零宽度高亮；音效：Web Audio 合成纸张声。
